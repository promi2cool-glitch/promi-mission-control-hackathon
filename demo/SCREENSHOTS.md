# Screenshot Package Checklist

Capture these five, in order, once the UI and a real verified run are available. Review each one before sharing anywhere — no secrets, no unrelated tabs, no private paths beyond what's already public in this repo.

1. **Hero Mission Control UI** — the main screen: status indicators, mission card, pipeline.
2. **XO live session** — the XO Space view of the real worker session (`7d8303e2-b890-4ce7-ac77-f6c7a8066f15` or a subsequent live run).
3. **Agent actions/files** — the execution evidence panel, or XO's own transcript view, showing tool calls and the changed file.
4. **Verification PASS** — the verification hero panel with 12/12 checks and the PASS badge.
5. **Architecture graphic/page** — `docs/architecture/ARCHITECTURE.md`'s diagram, rendered or screenshotted.

Do not automatically publish any of these — this checklist is for manual capture and manual review before use in Devpost or the video.
